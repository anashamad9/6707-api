How to use this API

1
Copy the endpoint link

Use the button above. The endpoint is public and does not require a username, password, or API key.

2
Paste it into your app or reporting tool

Use it anywhere that accepts a JSON URL, or fetch it with JavaScript, Python, Power BI, Looker Studio, or another data tool.

3
Read the transactions array

The response has a transactions array. Each item includes the transaction ID, offer ID and name, status, payout, revenue, sale amount, date, and GEO.

4
Refresh once per day

The source is checked automatically every day at 04:00 Amman time. The JSON changes only when the Google Sheet data changes.

Code examples

curl api/transactions.json
const response = await fetch("api/transactions.json");
const data = await response.json();
console.log(data.transactions);
import requests

data = requests.get("YOUR_API_LINK").json()
for transaction in data["transactions"]:
    print(transaction["offer_name"], transaction["sale_amount"])
